# mppt

Implémentation et outils autour du suivi du point de puissance maximale (MPPT) pour systèmes photovoltaïques.

## Statut
Ce projet est en cours de construction. Ce README sera complété avec l’installation, l’utilisation et la documentation technique.

## Objectifs
- Explorer différents algorithmes MPPT (Perturb & Observe, Incremental Conductance, etc.)
- Fournir des outils de simulation et d’analyse des courbes I–V
- Préparer une base pour une intégration embarquée (microcontrôleur)
